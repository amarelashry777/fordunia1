DUNYA BIRTHDAY PREMIUM ❤️

الباسورد: تونيا

1) افتحي index.html لتجربة الموقع.
2) الصور: ضعيها في photos ثم اكتبي أسماءها في script.js.
3) الفيديوهات: ضعيها في videos ثم اكتبي أسماءها في script.js.
4) التسجيلات: ضعيها في audio ثم اكتبي أسماءها في script.js.
5) الموسيقى: ضعي الأغنية في audio واكتبي اسمها في musicFile داخل script.js.

مثال:
const photos = ["dunya1.jpg", "dunya2.jpg"];
const videos = ["memory.mp4"];
const audios = [{file:"voice.m4a", title:"تسجيل ليكي ❤️"}];
const musicFile = "song.mp3";

مهم: قفل الباسورد الموجود هنا مناسب لموقع مفاجأة محلي، لكنه ليس حماية أمنية حقيقية لأن كلمة السر موجودة داخل JavaScript.
